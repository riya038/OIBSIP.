# Tribute Page – Sardar Vallabhbhai Patel

A beautifully designed tribute webpage dedicated to Sardar Vallabhbhai Patel, also known as the "Iron Man of India". This project was created using HTML, CSS, and JavaScript as part of an internship Level 2 Task.

---

## 🚀 Features

- Modern and responsive tribute page
- Elegant UI design with smooth layout
- Biography and achievements section
- Inspirational quotes
- Interactive JavaScript demo button
- Image gallery section
- Timeline of major life events
- Fully responsive design for mobile and desktop

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 About the Project

This tribute page highlights the life, leadership, and contributions of Sardar Vallabhbhai Patel in unifying India after independence. The webpage focuses on clean design, readability, and responsive user experience.
