# TaskFlow Pro – To-Do Web App

TaskFlow Pro is a simple and modern To-Do Web Application built using HTML, CSS, and JavaScript.

This project was developed as part of Internship Level 2 - Task 3.

---

## 🚀 Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Separate Pending and Completed sections
- Task statistics
- Local storage support
- Responsive design

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 📂 Project Structure

project-folder/

├── index.html  
├── style.css  
├── script.js  
└── README.md  

---

## ▶️ How to Run

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser
